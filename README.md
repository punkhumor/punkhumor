# 智家 · Home Hub

米家风格智能家居控制 App（Flutter）。**v1.1.0 可真实控制局域网电器**。

- 源码：[`home_hub/`](./home_hub/)
- 说明：[`home_hub/README.md`](./home_hub/README.md)
- APK：**[`releases/home_hub-1.1.0.apk`](./releases/home_hub-1.1.0.apk)**

## 快速使用

1. 安装 APK，手机与电器同一 Wi-Fi  
2. 打开智家 → 添加 → **手动添加** → 填 IP、选 Shelly/Tasmota/Yeelight/ESPHome  
3. 回首页拨开关，看到「已下发」即表示真实控制成功  
4. 米家/涂鸦等品牌：先接入 Home Assistant，再在「我的」同步
